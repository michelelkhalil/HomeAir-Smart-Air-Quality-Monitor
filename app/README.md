# HomeAir App / Dashboard

The HomeAir dashboard was developed using Flutter and connected to Firebase Realtime Database.

The original application source code was not included in the material used to build this repository package, so this folder contains documentation only.

Add the team's original Flutter source here only if you have permission to publish it.

## Demonstrated Functionality

- live sensor readings
- air-quality status
- connection state
- contextual recommendations
- historical data views
- Firebase-backed synchronisation

See the screenshots in [`../assets/`](../assets/) for the demonstrated interface.
